# Сайт персональных приглашений

Статический сайт персональных приглашений. Каждая страница приглашения
доступна по секретной ссылке вида `/i/<token>/`. Сборка выполняется
на Python 3 без сторонних зависимостей.

Реальные данные и медиафайлы хранятся вне этого репозитория; примеры
в репозитории — вымышленные.
